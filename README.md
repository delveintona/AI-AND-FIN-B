# AI-AND-FIN-B — 서울 아파트 12개월 선행 수익률 예측 (B 모델)

A 모델(`yangsoonho03-stack/AI-and-Finance`)은 규제·재건축 변수가 후행이고 검증 데이터가 오염돼 예측력이 없었다.
B 모델은 **규제·재건축·정권을 모두 빼고**, 돈의 흐름(금리·신용·공급)만으로 "지금 사서 12개월 뒤 팔면 어땠는가"를 예측한다.
이 저장소는 **기초 틀**이다. 변수·모델은 `code/config.py`만 바꿔서 실험한다.

## 설계 한눈에

| 항목 | B 모델 | A 모델과 비교 |
|---|---|---|
| 단위 | 서울 25개 구 × 월 | 동일 |
| 정답 y | 향후 12개월 수익률 ≥ 기준금리 + 3%p → 1 | 동일 (비교 가능) |
| 변수 | 금리·신용(`rates`), 공급(`supply`), 선택: 모멘텀·전세가율 | 규제·재건축·통제변수 |
| 시차 | 모든 변수 공표 시차 1개월 (모멘텀은 추가 시차 선택) | 동일 |
| 평가 | 1년씩 늘려가는 walk-forward + purge, AUC | walk-forward |
| 기준선 | 모멘텀만 / 학습평균(prior) | — |

## 분할 (먼저 고정, 중간에 바꾸지 않기)

### 사용법

1. **변수 고르기 (왼쪽 ①)**: 변수 체크박스로 하나씩, 그룹 체크박스로 한꺼번에 넣고 뺀다. 모멘텀은 기본 꺼져 있으니 그룹을 체크하면 들어간다.
2. **PCA 정하기**: 그룹 오른쪽 드롭다운에서 "PCA 1개/2개"를 고르면 그 그룹의 변수들이 성분 몇 개로 압축된다. 변수가 2개 이상일 때만 선택 가능.
3. **설정 (왼쪽 ②)**
   - 매수 기준: 정답 y의 기준(기준금리 + 몇 %p). A 모델과 비교하려면 3 그대로.
   - 규제 강도 C: 작을수록 계수를 강하게 누른다(과적합 방지). 기본 0.5.
   - 모멘텀 추가 시차: 모멘텀을 1~3개월 더 늦춰서 쓴다.
   - 모멘텀 기준선: 켜 두면 "모멘텀만 쓴 모델"이 비교선으로 같이 나온다.
   - 테스트 연도 포함: 최종 1회용. 평소엔 끄고 검증 연도(2013~2020)에서만 조정한다.
4. **모델 돌리기**를 누르면 몇 초 뒤 결과 탭에 나온다.
5. **읽는 순서**: AUC 카드(0.5가 무작위) → 연도별 그래프·표(해마다 얼마나 흔들리나) → 변수 영향 → 맨 아래 **결과 해석**.
6. **자료 확인**: 변수 이름을 누르면 출처·단위·기간·시계열 그래프가 팝업으로 뜬다. **사용 중인 축** 탭은 지금 켜진 구성과 학습 가능 시점, **전체 자료** 탭은 정답 y의 정의와 쓰는 파일 목록이다. **기본값으로**를 누르면 config.py 기본 구성으로 돌아간다.

### 주의
- 내 컴퓨터에서만 접속된다 (127.0.0.1). 터미널 창을 닫으면 꺼진다.
- `config.py`나 `catalog.py`를 고치면 서버를 껐다 켜야 반영된다. 화면에서 바꾸는 설정은 바로 적용된다.
- 설정을 여러 번 바꿔 가장 좋은 값을 고르면 검증 연도에 과적합된다. 연도별 AUC가 크게 흔들리므로 작은 차이는 신호로 보지 않는다.
- 결과 해석은 규칙 기반 문장이다. 숫자를 읽어 주는 보조 도구이지 결론이 아니다.

## 변수를 바꾸는 법 (`code/config.py`)

- 모멘텀 넣기/빼기: `ACTIVE_GROUPS = ["rates", "momentum"]` (기준선은 `BASELINE_MOMENTUM`)
- 모멘텀 시차: `MOM_EXTRA_LAG = 1` ("1개월 전 모멘텀")
- 전세가율 강건성: `ACTIVE_GROUPS`에 `"valuation"` 추가 (2012-01 이전은 역산값)
- 금리 변수 PCA 묶기: `PCA_GROUPS = {"rates": 2}`
- 매수 기준 강건성: `PREMIUM = 2` 또는 `5`

## 공급 자료와 PCA (`03_supply.py`, `04_pca.py`, `report/B_pca.md`)

| 변수 | 출처 | 시작 |
|---|---|---|
| `permits_12m`, `permits_apt_12m` 인허가(가구) 12개월 합 | KOSIS DT_MLTM_1948 | 2008-01 |
| `unsold` 미분양 재고 | KOSIS DT_MLTM_2082 | 2007-01 (그 이전은 12월 값뿐) |
| `starts_12m` 착공, `completions_12m` 준공 12개월 합 | KOSIS DT_MLTM_5386 / 5372 | 2012-01 / 2011-07 |

- **금리**: 수준 3개(기준금리·주담대금리·국고채3년)는 PC1 하나가 93%를 설명 → `rates_level`로 묶어 PCA 1개. 스프레드·M2는 `rates_other`로 따로 둔다.
- **공급**: 인허가·착공·준공은 PC1이 76% (공급 파이프라인 한 축). 미분양은 이들과 거의 무관한 별도 축이라 같이 PCA하면 뜻이 흐려진다. 착공·준공은 2012년부터라 `supply_ext`로 분리.
- PCA는 walk-forward 학습 구간 안에서만 맞춘다 (`04_pca.py`는 전체 기간 탐색용).

## 현재 상태 (검증 연도 2013~2020)

기본 설정(`rates_level` PCA1 + `rates_other` + `supply`)의 AUC 평균 0.62, 모멘텀 기준선 0.46.
다만 연도별 AUC가 0.2~0.9로 크게 흔들리고 PCA 유무·조합에 따라 0.4~0.6을 오가서, 8개 연도로는 우열을 가리기 어렵다. 테스트 연도는 아직 보지 않았다.
